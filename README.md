
# TASKTWIN

### Practise. Interact. Improve.

TASKTWIN is a workplace conversation practice platform designed to help students, fresh graduates and job seekers build confidence before entering professional environments.

It provides realistic workplace scenarios where learners can practise responding to challenging situations and receive feedback to improve their communication and problem-solving skills.

## Problem

Many students graduate with theoretical knowledge but lack practical experience handling real workplace conversations.

Situations such as dealing with an unhappy customer, resolving a complaint or communicating professionally can be difficult without prior practice.

## Our Solution

TASKTWIN aims to make workplace preparation more practical through interactive simulations.

Learners can:

- Choose realistic workplace scenarios.
- Practise responding to professional situations.
- Interact with simulated customers and colleagues.
- Receive feedback on their responses.
- Improve communication and problem-solving skills.

## Current Demo

This repository currently contains an early frontend concept demonstration.

The demo includes:

- Responsive landing page.
- Emerald and white visual design.
- Sample delayed-order customer service scenario.
- Text-based response submission.
- Illustrative feedback and scoring.

**Important:** The current demo does not use a live AI model. Its feedback is generated through basic JavaScript keyword checks and is intended only to demonstrate the concept.
